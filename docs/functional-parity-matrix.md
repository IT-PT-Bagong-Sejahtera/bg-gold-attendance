# BG GOLD Attendance Functional Parity Matrix

This matrix is the source of truth for functional parity. StaffAny is used only as behavioral evidence; all BG GOLD code, copy, data models, and visual design are clean-room work.

## Status definitions

- **Discovered**: confirmed in the APK or its runtime metadata.
- **Planned**: specified for BG GOLD but not implemented.
- **In progress**: implementation exists but is incomplete or unverified.
- **Implemented**: code exists and local checks pass.
- **Verified**: the complete user flow has passed its stated acceptance evidence.

## Evidence baseline

- APK: `StaffAny+Clock-In+&+Scheduling_1.170.0_APKPure.apk`
- Package: `com.staffany.pixie`, version `1.170.0`
- Client: React Native/Expo with Hermes bytecode
- Observed API base: `https://api.staffany.com`
- Observed attendance endpoints include `/cico`, `/cico/notify-spoofing`, `/clock-requests`, `/clock-records/override`, `/clock-settings`, and dynamic QR validation by section.
- Observed attendance record types include clock in/out, approval requests, automatic approval/clock-out, scheduled and unscheduled breaks, and work-more.
